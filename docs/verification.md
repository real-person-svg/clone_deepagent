# 网络研究与 Agent 验证

验证时间：2026-11-01，北京时间。所有真实调用均使用独立临时 SQLite 数据库；默认工作空间和 `.env` 未改写，密钥未写入报告。

## 实现与自动化验证

- Agent 选择器位于输入框左下角，与数字员工页面读取同一个已发布员工接口。选择结果进入持久化 `agentId`，实际执行对应员工的提示词、工具权限和版本；旧任务默认兼容研究主 Agent。
- 删除顶部旧选择器、SQLite 状态文案、输入区下方核对提示和快捷键提示。保留 Enter 发送、Shift+Enter 换行。
- 资料研究与研究主 Agent 可使用不需要搜索密钥的公开 RSS 搜索，采集候选及页面实际链接，再读取原文。搜索摘要不作为报告证据。正文采集沿用 DNS 地址固定、重定向校验、公共地址限制、超时与体积上限。
- TypeScript、生产构建、46 项自动化测试、2 项 Google Chrome 浏览器回归通过。覆盖动态菜单与真实 agentId、搜索到采集和报告、来源授权范围、预算压缩、引用修正、取消、checkpoint 恢复、来源巡检和旧库迁移。

## 真实网络与模型评估

| 场景 | 实际结果 | 判断 |
| --- | --- | --- |
| 不提供 URL，资料研究员工自行研究剪映/CapCut | 11 次模型请求；4 次搜索实际执行，另 2 次被搜索上限拒绝；6 份网页正文采集成功；最终报告引用 5 份 | 能自主发现并整理官网、定价和授权资料；没有用预置资料或搜索摘要代替原文 |
| 独立证据核验员工读取原文核验报告 | 4 次模型请求、10 次原文检索，生成核验表及修正结论 | 能指出部分过度推断和引用问题；核验结果本身仍需复核 |
| 长上下文及历史约束治理 | 初始回放 900,827 字符，第一次请求缩到 11,559 字符；后续请求最高 57,750 字符；5 次模型请求均在 75,000 字符预算内 | 找回早期 SCOPE-800 约束，保留仅剪映中国区、5 人、800 CNY/月、禁止换汇；价格证据不足时没有估算预算 |
| 更严格的用户预算 | 指定“最多1轮检索、1个页面采集”，实际执行1次搜索与1次采集，生成带引用的功能摘要 | 服务端执行更小的用户预算，不只依赖模型遵守提示 |
| 真实模型请求期间取消 | 状态 `cancelled`，0 份报告 | 中止后不会发布成功报告 |
| 首轮真实研究的重测 | 首轮只获得 3 份正文；加入实际页面链接跟随及更严格证据提示后，重测获得 6 份正文 | 修复确实改善了协议与定价资料覆盖，但动态页面仍可能不可采集 |

长上下文场景有意重复真实官方原文并插入带明确测试标签的历史记录，以验证预算和回放，不是一次自然增长的长对话。checkpoint 中的模型续轮字段保持原样。初次人工压力 checkpoint 缺少提供者要求的 `reasoning_content`，导致 HTTP 400；修正评估构造后重放成功，完整评估也已通过。没有把这一初次失败计作成功。

完整研究评估也暴露了“提示要求3轮，但程序只执行默认4轮硬上限”的预算缺口。已增加对明确的更小检索/页面数量约束的程序执行与剩余预算返回，并用独立的1轮/1页真实任务复测通过；中文数字与默认上限也有回归覆盖。

真实任务的恢复与引用、工具幂等性另由自动化回归覆盖。上述取消与少量真实研究不能证明所有网络环境、所有模型及长期无人值守运行都稳定。

## 准确性与真实性检查

人工结合保存的原文及独立核验结果检查了以下问题；没有把模型复核当作真实性认证，也没有给出缺乏样本依据的“准确率 100%”。

| 检查点 | 发现与处理 |
| --- | --- |
| 来源真实性 | 网页由实时 HTTP 采集，保存 URL、观察时间、SHA-256 和原文；所有报告内部证据引用均对应本轮读取过的真实网页记录 |
| 免费与登录 | 首轮曾由“无需信用卡”扩大为“无需登录”；已在 Agent 提示中明确禁止这种推导，核验中也单独检查 |
| 地区与币种 | SGD 只能证明该页面显示的币种，不能单独证明访问者或报价适用国家；“新加坡渲染”应删除或明确降级为未证实推断 |
| 域名与主体 | 不同域名不能证明不同法律主体或订阅不可互通。主体信息必须来自协议正文，订阅互通性没有证据时保持未知 |
| 商用许可 | 对素材标记、混用限制等必须保留原文限定；核验发现有引句未逐字对应，不能作为精确引文使用 |
| 动态价格 | 定价正文包含多个席位与周期的展示值，不能仅凭抽取顺序确定可购买报价，也不能仅凭阶梯变化认定网站错误；需结合实际购买界面复核 |
| 缺失信息 | 剪映中国区可执行 CNY 报价、团队席位及总预算仍缺证据。后续确实采集到会员与 AI 付费协议，但没有据此补造价格 |
| 核验自身的局限 | 核验报告对页面数量及个别推断的表述也有简化；程序采集记录才是数量依据，不能直接将核验 Agent 的判断当作黄金答案 |

当前能支持有证据、能回查的商业化研究；价格适用条件、授权语义、动态页面和最终商业判断仍需人工复核。免费公开搜索可能限流、返回无关结果或改变格式，程序会返回缺口和失败，不伪造来源。
