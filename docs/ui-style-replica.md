# 工作台界面

界面采用浅灰侧栏、白色内容区、绿色状态提示和适合长文本阅读的聊天区域。桌面侧栏可折叠，移动端默认收起；Agent 选择器支持键盘操作，来源原文侧栏支持焦点管理。

- 输入框左下角的 Agent 选择器与数字员工共用已发布列表；菜单向上展开，支持键盘选择和移动端滚动。顶部旧选择器、SQLite 状态文案与输入框下方提示已移除。
- 聊天入口仅连接服务端真实模型；未配置模型时显示配置提示并禁用发送。
- 来源资料从空列表开始，支持用户文本和官方公开页面；每份资料保留原文与观察时间。
- 报告展示引用、执行状态和时间；没有来源的输出标记为部分结果。
- 订阅必须选择真实网页来源，区分来源内容更新与商业化结论。

浏览器回归位于 `tests/workspace.spec.ts`，覆盖桌面研究、报告与原文、资料导入、配置编辑、来源选择限制，以及移动端附件与取消任务。
